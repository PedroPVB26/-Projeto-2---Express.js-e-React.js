# Projeto 2 Express.js e React.js
 Projeto 2  da disciplina de desenvolvimento fullstack

## Bibliotecas utilizadas
- *pg*: comunicação com o PostgreSQL
- *dotenv*: leitura das variáveis de ambiente do .env
- *prisma*: ORM
- *bcrypt*: hash e comparação de senhas
- *jsonwebtoken*: Geração e validação de JWT
- *express-rate-limit*: Limitar tentativas de login
- *cors*: CORS
